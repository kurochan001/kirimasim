## アサーションの演算子と評価の時点

### P2 で手続き内から使えるサンプル値関数

サンプル値と比較は IEEE 1800-2023 16.5.1、16.9.3 に従う。最初の対象は静的な packed 整数変数とネット、定数による選択、整数定数、およびそれらに対する副作用のない組み込み整数演算とする。宣言時の初期値はエラボレーション時に定数と分かるものに対応する。他のオペランド形式は位置付きで診断する。

- `$sampled(e)` は各オペランドのサンプル値を使って式を評価する。時刻0の静的変数には宣言時の初期値、初期値がないときには型の既定値を使う。ネットには型の既定値を使う。以後は各シミュレーション時刻の Preponed で取得する。同じ時刻の Active・NBA・Reactive を何周しても同じサンプルを読む。この関数にクロックは不要。
- `$stable(e)` と `$changed(e)` は現在のサンプルと、**現在より前のシミュレーション時刻**のうち対象エッジがあった直近のサンプルを比較する。先行エッジがなければ既定サンプルで求めた式の値と比較する。X・Z を含む全ビットを比較し、結果は互いに反対の1ビット値となる。同一時刻に複数のエッジが起きても履歴サンプルは一つとする。分岐によって関数呼び出しが実行されないエッジでも履歴は進む。
- 履歴用クロックの最初の範囲は、静的に決まる1ビット信号の単独の posedge または negedge とする。明示的な指定、および16.14.6に従い外側の手続きのイベント制御から推定できる場合に対応する。履歴はエラボレーション後のインスタンス内の信号とクロックの組に属する。複合・ガード付きのクロック、これ以外のクロック推定、他のサンプル値関数は後続で扱う。

開発中の SIR は各入力について、インスタンス、元の宣言と固定 packed 範囲、型付きの既定サンプル、現在のサンプルを保持する内部スロットを記録する。履歴を持つ入力にはクロック範囲、エッジ、過去のサンプルの内部スロットも記録する。検証器は範囲、型、クロック幅と内部スロットの所有関係を確認する。形式1の読み戻しでレコードを保存する。サンプル取得と履歴更新はスケジューラが担当し、式はサンプルに対する既存の型付き演算で評価する。
