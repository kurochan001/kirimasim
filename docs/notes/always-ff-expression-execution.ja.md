# always_ff の式のイベント制御

[English](always-ff-expression-execution.md)

IEEE 1800-2023 9.2.2.4・9.4.2 が許す式のイベント制御を接続しました。SIR_SPEC 7.1 の
ff の種別・単一writer・追加のイベント制御の禁止を保ち、7.2 の既存の型付きwatch/iffと
カーネルの監視を使います。always_ffを制限のないgeneralへ置き換えません。

`Lowerer::signalOperand` は固定slot範囲か型付きwatchを選び、通常のwait.eventとffのトリガが
共有します。トリガは範囲またはwatchの片方と、辺・任意のiffを持ちます。watchの種別・整数の戻り値・
借りるプロセスのフレーム・入る前のautomatic範囲の生存を検査します。writerの効果と本体の待機禁止も保ち、
VMは値を作る前に式トリガのメタデータを再検証します。format-0の表示は `posedge(watch @N)` で、
既存の固定トリガの表示は同じです。guardと呼び出しの効果の数え方は既存のものを使います。

VMは既存のwatchMonitorを使い、固定購読と監視を同じカーネルの待機世代へまとめます。
callbackのポインタを渡す前に格納域を確保します。全フレームとfinalを登録してから、time-zeroの
initialを実行する前に監視を張ります。最初は基準値を評価し、ff本体は動かしません。
監視開始時の実行エラーでもfinalを動かせます。本体が終わるたびに新しい待機と基準値を作り、
4値の辺、辺を指定しない値全体の変化、iffの評価時機、同値の書き込み、関数内の作業変数の除外、
ヒープの参照先の置き換えは既存カーネルが扱います。固定選択への計装でもffの制限を保ちます。
classオブジェクトとevent観測の未接続の組み合わせは、既存の境界を保ちます。

生成器 `gen_ff_expression_matrix.py` は独自814ソースを追加します。module/interface/generate、1/32/65/129/257ビットの2/4値、
XOR・実行時選択・固定配列・関数・条件式・reduction・反転、各辺、iff、起動時の変化、
2/9/17プロセスと項目、dynamic array/queueの参照先の置き換えを調べます。期待回数は4値の辺の表と
1回の書き込みごとのNBA後の観測から求め、参照側の出力を期待値にはしません。
10単体は生成メタデータ、不正な参照/種別/所有/範囲、正常な通常alwaysとのwriter比較、追加の待機、
未生存のフレーム、計装、監視開始エラーとfinal、関数内の作業変数、実行前の拒否を検査します。
変異12個を用意しました。

保守者は元のalways_ff_expressionの入力を終了0・stdoutなし・エラー診断なしへ分類する変更を承認しました。
未対応診断3行の移行は期待値だけの `e56de308` です。他の拒否入力、既存スイート本体、性能予算は保っています。
この有限のテストからP1の機能同等性やspecify/VPIの対応完了は示しません。
