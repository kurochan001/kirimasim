# fork内の宣言と親での初期化

[English](fork-local-declarations.md)。実装`c6d9c3d`、検証日2026-10-24。
P1全体とIcarus全範囲の対応は未完了です。

## 実装した動作

fork内の宣言は、実行する子を作る前に親の実行スコープで変換します。宣言を子に数えず、
`join_any`を早く満たさないようにします。static変数は既存の共有スロットを使い、
時刻0より前に1回だけ初期化します。automatic宣言は入るたびに親フレームで初期化します。
宣言しかないforkは、3つのjoinすべてで子も待機も作りません。名前付きforkの初期化式では
`%m`などの字句スコープも保ちます。

承認済みP1の範囲のもと、既存のSIR_SPEC 3.3・7.4・7.5とSCHEDULER_SPECの寿命・forkの
規則を実装します。カーネルAPI、SIR命令、依存、新しいスケジューリング方針は加えません。
初期化式の式・呼び出し・型付き記憶域も、既存の値やコピーの規則を使います。
暗黙のstatic初期化に対するslangの警告は維持して検査します。

[英語版の例](fork-local-declarations.md#implemented-behavior)では、fork内のstatic変数を
片方の子が9へ更新し、後の子が9を表示します。宣言が余分な子となって先に完了することは
ありません。

**automatic変数の捕捉は未対応です。** 子が並列ブロックや外側の呼び出しのautomatic
変数を読み書きする形は受理しません。共有する同一性、親フレームの保持、外へ逃げる寿命は、
この版の時点では、SIR_SPEC 7.5でまだ詳細な契約が必要です。[捕捉の契約](automatic-capture-proposal.ja.md)は
2026-10-25に承認され、実装は残作業です。別々の子へ値をコピーして同等と扱うことは
しません。automaticのevent・集約宣言も、型のフレーム表現が未実装の制限を保ちます。

## 独自の実行検証

[ジェネレータ](../../tools/gen_fork_declaration_matrix.py)で**独自72ソース**を追加しました。
64件は8種類の実行場所、1/32/65/129ビット、2値・4値を横断し、staticの共有、繰り返しの
進入、1回の初期化、3種類のjoinと完了時刻を検査します。残る8件は、捕捉のないautomatic
初期化の順序と同時呼び出し、子がいない形、字句スコープ、短絡制御、配列・実数・文字列、
キュー・event、後の処理を始める関数を呼ぶ初期化式を検査します。

[ソース・出力のハッシュと4実行系の記録](../measurements/2026-10-24/fork-declaration-source-validation.json)で、
現nativeの72件成功と、保持した旧版（表示`e4376f1d029d`、nativeソース`57a64ef`）の
72件未対応を記録しました。Icarus 13.0 stableと14.0開発版は、どちらも58件で一致、
9件はコンパイル拒否、5件は実行/出力の差でした。拒否8件は明示的な寿命指定、もう1件は
既存の関数からforkする機構です。実行/出力の差にはsignal 6による終了2件を含みます。
それらを期待値の置き換えにはせず、他のシミュレータのソースやテストも読んでいません。

[コンパイル済みの誤実装4種類](../measurements/2026-10-24/fork-declaration-negative-controls.json)も
新ソースが検出しました。宣言を子にする、automatic初期化を落とす、static初期化の副作用を
繰り返す3種類は、実際の新stdoutの不一致で検出します。空のforkを出す別の1種類は、
実際のソースのSIR検証失敗で検出します。アンカーや判定器の自己検査は証拠から除き、
終了後はソースを戻して再ビルドしています。

独立したCLI検査は、全join種類で位置付きのautomatic捕捉拒否3件と、捕捉なしの
親初期化の受理3件を確かめます。完全なローカルCIの4構成と静的検査も成功しました。
件数は[現在の進捗](p1-icarus-progress.ja.md)にあります。既存SIR出力29件、suiteの本体・
期待値、性能回数は変えず、新しいテストでは既存のslangの警告も保ちます。

## レビューの分離と有限の比較

宣言だけの6種類の実行場所を含む過去のCLI入力は、1バイトも変えていません。
古い拒否の期待値だけを`a431909`、`codex/fork-local-declaration-expectations`へ分離し、
6.21・9.3.2を根拠に記録しました。実装レビューはその期待値ブランチをベースにします。
これはローカルのレビュースタックで、別々のリモートPRを作成したという意味ではありません。

[比較一覧](icarus-13-comparison.ja.md)は独自81プローブになりました。同じ一覧で、
旧nativeの差分は13.0/開発版で22/28件、現行は21/27件です。staticのfork宣言は通過し、
新しく加えたautomatic共有捕捉は両参照で通り、nativeでは未対応です。以前の79件の
状態と参照不一致4/7件は変わりません。従来の差分20/26件は小さい一覧の値として保ち、
全機能の対応とは扱いません。性能とLinuxでの結果は再測定していません。
