# スカラーmodule pathのカーネル検証

[English](module-path-kernel-validation.md)。2026-11-01。

[承認済みspecify契約](specify-p1-proposal.ja.md)の最初の実装として、独立した
端点の参照実装、12遷移の遅延正規化、元の物理strength originを通じた
Context所有のスカラー予約処理を追加した。この段階だけでは**ソースのspecify実行を
受け入れず、P1の完了も主張しない**。SIRとフロントエンドの接続は後続の変更で行う。
既存の拒否期待値と凍結した外部比較の集計は変えていない。

新規78テストは、遷移と遅延個数の全60組、最新入力と同時刻の最小遅延、時刻ゼロと
辺の資格、広いスロットの入力位置、max（分布遅延の到着、path期限）、ゼロと期限超過の
Active公開、完全な寄与の慣性置換、予約をまたぐforce、メタデータだけの変更、Context間の
独立性、不正な登録、表現範囲外の遅延、割当失敗後の再試行を検証する。
共有ユニット実行ファイル全体の1,018件が通過し、公開ヘッダはC++20でコンパイルできた。

[コンパイルした9変異](../measurements/2026-11-01/module-path-kernel-native-controls.json)は
すべてビルドでき、変異登録簿の検査以外の意味を検査するテストで失敗した。
Xからの遷移、古い入力の選択、同時刻の選択、遅延の加算、ゼロのInactive公開、古い世代、
通常入力の記録欠落、strength入力の記録欠落、force中の機能到着の抑制を故障として入れた。
ソースをバイト単位で復元し、78件の基準テストが再度通過した。記録のソースハッシュは
相対パスで示す。`tools/mutants.py`へ登録済みで、通常の全テスト実行では
`--only 'scalar module path:'`で選べる。

対象のclang-tidy（LLVM 23.1.4）、禁止構文、変異アンカーの検査は通過した。
全devと件数更新、他プロファイルの統合検証はソース接続後に行う。
この記録ではlocal CI全体の通過を主張しない。
