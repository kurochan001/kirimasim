# P1：Icarus `wire real`拡張を任意とする

[English](p1-wire-real-exception.md)

除外にはIcarus拡張への依存の確認が必要で、`real`を含むだけでは対象外にならず、標準のreal機能の検証と独立した不具合の報告を残す扱いは[テスト分類の規則](../spec/TEST_SUITE.ja.md#任意拡張の分類)で確認できます。

2026-11-01の保守者の明示的な依頼により承認済みです。正本は
[P1_SCOPE](../spec/P1_SCOPE.ja.md)と
[TEST_SUITE](../spec/TEST_SUITE.ja.md#任意拡張の分類)です。

## 完了条件

Icarus Verilog 拡張である `wire real` への対応は、P1 の必須条件に含めません。
この拡張への依存が確認されたケースは、未サポートであっても P1 の達成を妨げません。
Icarus 13.0の対応範囲の目標にこの例外を適用し、拡張への未対応だけをP1のブロッカーや
IEEE 1800標準機能の不足とは判定しません。

`real`変数・実数演算、標準で認められるreal変数への単一の連続代入、
`nettype real`によるユーザー定義ネット型は例外に含めません。
既存のP1の扱いを保ち、`nettype real`を新たな必須機能にする変更でもありません。
実行実装の追加・削除・無効化はなく、既存のソーステスト・期待値も変更しません。

## 確認済みのケースと集計

対象外とする機能プローブは**`real_net`の1件だけ**です。独自ソースは`wire real r`を宣言し、
1.5を代入して遅延後に表示します。目的がIcarus拡張に依存し、独立した標準real機能の回帰検査ではありません。
末尾の改行を含むソースのSHA-256は
`f70a56afc6f239649b7f871333a33d12340a57c1106cc7d77b9ca7364bd0f69f`です。
`P1_OPTIONAL_PROBES`の確認済みの名前とhashが両方一致した場合だけ除外します。
変更したソースや標準機能と混在させたソースは依存の再確認が必要で、既定では評価対象です。
`real`という部分文字列だけで除外することはありません。

[新しい176件の記録](../measurements/2026-11-01/icarus13-wire-real-optional.json)は、
Icarusコンパイラ・ランタイム**13.0 stable**、native実行ファイル`a525b8414e1c`
（AppleClang 21.0.0.21000334）と改定したPython判定ツールによる結果です。

- **総数176件、P1評価対象175件、対象外1件**です。
- 生の差`gaps`は3件、`p1_required_gaps`は`specify_path`と`dense_udp_coverage`の2件です。
- `real_net`は位置付きの無効なネット型の診断を持つ`run_failed`・終了コード2のままです。
  追加のコンパイル専用検査も標準出力なしの終了コード2で拒否します。
  単独の`--require-parity`実行は0を返し、必須の`specify_path`の単独実行は引き続き1を返します。
- `dense_udp_coverage`のフロントエンドの時間上限は残し、`independent_failures`にも記録します。
  今回の決定で許容したものではありません。
- 参照の出力不一致25件は別に保ちます。参照のクラッシュ・上限も別記し、kirimasimの不具合には加えません。

全176件のソースhash・期待値のバイト列・nativeの結果・参照の状態と終了コードは前の統合記録と一致します。
失敗した参照`dynamic_query_dimension`の標準出力だけ一時パスが変わり、新しい公開記録では
そのパスを伏せて加工の内容を記録します。成功した標準出力は不変です。過去の記録のバイト列は保ちます。
日付付きの95件の集計は別に**評価対象94件＋対象外1件**と再分類し、生の差6/6件、
必須範囲の差5/5件（stable/development）を分けます。範囲の見直しであり、再測定やPASSへの変更ではなく、
機能範囲が未達という判定も保ちます。

## 母集団の監査と確認

独自スイート`41085fe3432b`の固定母集団は**1,466件**のままです。ソース設計を確認し、
明示的な`wire real`宣言はありませんでした。sv-testsの固定版
`15490e95fd978ada1c1dc59b7c4b53a7edb23b78`の手書きソースも、選択した
**344件**のsimulationテストには明示的な`wire real`がありません。
コメント・文字列を除いた確認であり、あらゆるマクロ展開や依存の確認を主張するものではありません。
両母集団に新たに確認された対象外はありません。合格率の分母・runnerの規則・gate一覧・nightlyは不変です。
外部母集団の新たな実行やLinuxの結果を主張しません。

既存の`ports/fixed_array_port_typed_real_net.sv`は標準の`input real`と`output var real`、
単一の連続代入を使い、`wire real`を宣言していないので評価対象のままです。
選択した既存のreal/shortrealの値・型付きポートの**8件**は、変更なしで全件成功しました。

`tools/p1_wire_real_scope`は**21の動作シナリオ**を確認します。任意拡張の通常のコンパイル拒否、

内部エラー、コンパイル検査の失敗、実行時の失敗を含み、全件成功です。

名前だけの除外、gateからの独立した不具合の隠蔽、任意ケースのPASS捏造という3つのPython変異を検出しました。
元のツールを復元後、正の検査も成功しています。
