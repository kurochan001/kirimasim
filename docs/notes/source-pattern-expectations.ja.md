# ソースのパターン書式の旧拒否期待値を移行する

[English](source-pattern-expectations.md)

承認済みのSYSTEM_TASKS 3.9とIEEE 1800-2023 21.2.1.6に合わせる期待値だけの変更です。
実行時の実装は含めません。

元の`tests/cli/unsupported_matrix/display_p.sv`のバイト列は変更しません。
従来の位置付き`%p`拒否診断8件を、コンパイル成功へ移します。
実行される`$display`は7回で、イベント制御のalways本体はコンパイルされますが発火しません。
入力を`ACCEPTED`へ移し、CLI検査は各行が数値5である7行を要求します。
`%p`のフィールドの空白幅には依存せず、`%p`の標準出力goldenファイルも追加しません。
その他の拒否診断・受理済み入力の検査は保ちます。

実行時フォーマットの元の2入力（`$sformatf`と`$sformat`各1件）も、生成するソース本体は保ちます。
7の`%p`変換が成功し、後続処理を実行して最終結果7を保持することを確認します。
parse・SIRの検査も残します。正の検査は警告・エラー・内部エラーを拒否し、
数値の周りの空白だけを無視します。不正な書式、X/Zの書式、引数の過不足、空引数、
評価順・代入先の書き戻しなど、他の検査も維持し、合計26ケースです。

移行は実装と別の`fix/p1-pattern-expectations`ブランチに置きます。
新しいnative実行ファイルで既存CLI runnerの両方が成功し、生成器の`--check`も成功しています。
suiteのソース、既存の処理回数の予算、単体テストのアサーションは弱めていません。
P1全体の完了を示すものではありません。
