# 固定配列の条件演算の期待値修正

[English](fixed-array-conditional-expectations.md)

状態：**承認済み（2026-10-29）**。[Issue #60](https://github.com/kurochan001/kirimasim/issues/60)
の [PR #107](https://github.com/kurochan001/kirimasim/pull/107) で、保守者がこの期待値修正を明示的に
承認しました。[AI_POLICY](../spec/AI_POLICY.ja.md) の期待値保護規則に従い、
期待値だけの PR を実装と分けます。

IEEE 1800-2023 11.4.11 は、条件が不明な unpacked 配列の結合を要素全体ごとに定めます。
等しいと確定しない要素には、7.4.5 の Table 7-1 にある型の既定値を使います。
異なる logic ベクトルなら、両オペランドで一致するビットも含め、全ビットが X です。
スカラーの packed ベクトルのビット単位の結合規則は使いません。

生成されたポートテストのうち、幅 8 と 65 の値版・副作用版、計 4 件の出力の 3 行目を直します。
要素の組は両方とも異なる値（1 と 7、2 と 9）なので、結果の両要素は全ビット X となります。
条件が既知の最初の 2 行は変えません。値版の呼び出し回数 0・0・0、副作用版の 1・2・4 も保ちます。

4 つのソースは `:lrm:` ヘッダへ 11.4.11 を加えるだけで、テスト本体はバイト単位で同じです。
ジェネレータはこのヘッダと修正した要素の既定値を再現し、他の生成ケースは変えません。
削除・改名・スキップ・検査の緩和はなく、PR に `src/` や性能期待値の変更も含めません。

`tools/gen_fixed_array_port_matrix.py --check` は生成した全 358 件を検証します。
対応する実装には、要素全体、入れ子の集約、メンバの既定値、オペランド評価の新規回帰テストもあります。
