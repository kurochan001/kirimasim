# event-NBAのref対象でpackedな親範囲を保持する

[English](event-nba-ref-windows.md)。2026-10-30。

refを通じて、静的に選んだpackedな親範囲内の実行時選択をevent-NBAの更新先にできます。
組合せ不足N03を、[SIR_SPEC 5.3](../spec/SIR_SPEC.md)と
[承認済みevent-NBA契約](event-nba-proposal.ja.md)へ接続する変更です。
既存の親範囲による切り詰めを使い、カーネルAPI・値の意味・命令・依存は追加しません。

参照先のビット対象に、親の絶対的な下位ビット位置と幅を必要な場合だけ保持します。
位置・幅が0なら、既存の要素全体の表現・出力を保ちます。親範囲付きでは
`parent=offset+width`を出力します。幅0で位置だけがある形、記憶域外の親範囲、和が
オーバーフローする範囲はverifierが拒否します。SIRは引き続きv1文法の固定前の診断用形式0です。

登録時に、捕捉した子の位置と値を親の範囲内へ切り詰めてから、記憶域上の位置を足します。
共有カーネルの既存の処理を使い、負の位置では右辺の対応する下位ビットも読み飛ばします。
親より上・X/Z・表現できない位置は書き込みを生みませんが、制御・回数・guard評価は保ちます。
境界警告も親の範囲で判定し、ソース位置ごとの一度だけの報告を維持します。

```systemverilog
module top;
  logic [1:0][7:0] value='0;
  event go;
  task automatic issue(ref static logic [1:0][7:0] r);
    int index=3;
    r[1][index] <= @(go) 1'b1;
    index=0;
  endtask
  initial begin
    issue(value);
    ->go;
    #1;
    $display("%h", value);
  end
endmodule
```

`0800`を出力します。子の添字が`r[1]`の範囲を外れても、`r[0]`は変わりません。
予約データは有効な書き込み範囲だけを保持するため、発行後に隣接ビットが変わっても、
適用時点の隣接ビットを保ちます。task終了後の寿命、repeat回数の共有、発行順、
NBA/Re-NBAの起点は既存のevent-NBA処理に従います。

packed構造体のメンバーと入れ子のpacked次元にも、同じ親範囲の情報を使います。
[固定配列ref](event-nba-ref-arrays.ja.md)では、捕捉したunpacked添字・部分配列の基点と
packedな親範囲を組み合わせられます。

## 検証と残る制限

[CLIの39ソース・234検査](../../tests/cli/run_event_nba_ref_window_tests.py)で、幅1/8/65/129の
2値・4値の親、正負・部分的に有効な位置、昇順・降順・負のpacked範囲、上下向き部分選択、
X/Z・広い位置、構造体の位置、入れ子次元、配列refの転送、共有する回数と発行順を検査します。
module・interface・program・generate・関数で、初期値4モードを実行します。
ソースの期待値はビットごとに独立に計算します。

[ユニット6件](../../tests/unit/event_nba_ref_window_test.cpp)は、ソースとASTの破棄後に
実行します。VMと`valsem`の91比較では、選んだ親だけを変更して元の値へ戻す参照計算を使い、
広い4値、64ビット境界、幅1の親、部分書き込み、極端な位置、X/Z、従来の要素全体を検査します。
適用時点の隣接値、戻った配列ref、空の書き込みのnative guard回数、不正な配置情報、
Contextの分離、親範囲による警告と重複防止も検査します。完了時の予約データ・制御・活動leaseは
解放されます。

親の位置消失、親の幅からの逸脱、右辺の下位ビット読み飛ばし漏れ、frontendの情報欠落、
親範囲の検証漏れ、要素全体での警告判定、空の制御の省略の7種類の故障をコンパイルして
検出しました。復元後の検査も成功し、既存の出力・SIR・PerfCountの期待値は変更しません。

親の位置も実行時に変わる形、親範囲そのものが記憶域外にある形は従来の未対応です。
親より広い部分選択をSlangが拒否する制限も緩めません。
[スカラーref経由の単一値全体の遅延NBA](delayed-ref-nba.ja.md)は接続しました（N01のスカラー形）。
[固定配列ref・packed選択への遅延NBA](delayed-ref-selections.ja.md)も接続しました。automatic変数・
動的コンテナ要素へのNBA、広いevent値の対応は残作業です。`51cda314`でのN03測定は過去の記録で、
今回の対応だけでP1全体や外部シミュレータとの完全な互換性を達成したとは判定しません。
