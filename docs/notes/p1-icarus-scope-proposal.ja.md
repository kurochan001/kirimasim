# P1の対象範囲の修正案：Icarus Verilogとの機能比較

状態：**承認済み（2026-10-23）**。
[P1_SCOPE](../spec/P1_SCOPE.ja.md)へ反映しました。実装は進行中です。

依頼の到達点は、P1の実行機能をIcarus Verilog 13.0以上の範囲にすることです。
既存のTEST_SUITE.mdの合格率の基準より広く、合格率だけでは達成と判定できません。

従来の仕様は関係する仕組みの一部をP3・P4へ送っていました。次の修正が承認されました。

- Icarusが対応する標準言語の実行機能を、必要に応じてP1へ前倒しします。
  動的なコンテナ、クラス、programの実行、VPI、スイッチレベルのモデルなどが
  対象です。意味と共通カーネルの構成を保ち、P2は引き続きC++生成とします。
- 現在の一覧で対象外とされているものでも、Icarusが対応するspecifyパスや
  タイミングの機能を含めます。詳細な意味は実装前に修正案をレビューします。
- 既存のP1の基準・期待値・厳密なフロントエンド診断を保ち、別途測定する
  互換性の一覧を追加します。比較の達成のために既存の期待値を緩めません。
- 標準の構文はIEEE 1800と承認済みの値・スケジューリングの規則で判定します。
  実装に任される選択や相手の不具合はそのまま再現せず、差異を記録します。
- Icarus独自拡張と外部インターフェースは別途一覧化します。厳密な受理規則に
  反する拡張は、文書化した互換オプションと意味の提案を実装前に用意します。
- 新しい依存・インストールには引き続き承認を必要とします。この案は依存を
  選定・承認するものではありません。

対象の仕様書はSYSTEM_TASKS.mdの段階表、SIR_SPEC.mdの動的な格納、
SCHEDULER_SPEC.mdのprogramとプロセス実行、VPI_SPEC.md、WAVEFORM.md、
README・P1_SUPPORTの段階の説明などです。個々の実装前に詳細な修正を行います。

無書式の `%u`・`%z` の出力は実装済みです（SYSTEM_TASKS.md 3.11）。
別件の[バイナリ入力の修正](binary-scan-proposal.ja.md)も2026-10-23に承認されました。
入力も共通の読み取り処理へ実装しました。

現在の比較用実行ファイルの表示は
`Icarus Verilog version 14.0 (devel) (s20260301-411-gca6b8d376)`です。
新しい開発版との比較であり、正確な13.0リリースでの実測ではありません。
13.0での互換性と全機能の同等性は未確認です。自作の仕組み別テストを実行し、
コンパイラとランタイムの版を記録して確認します。Icarusのソースやテストは
読み込み・取り込みません。公式の
[13.0リリースノート](https://steveicarus.github.io/iverilog/releases/v13-0-release-note.html)は
背景資料であり、全機能の一覧ではありません。
[独自拡張の一覧](https://steveicarus.github.io/iverilog/usage/icarus_verilog_extensions.html)も
比較対象を調べる資料で、コードをコピーする根拠にはしません。
