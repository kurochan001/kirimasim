# 多次元メモリへのバイナリ入力

[English](multidim-fread-execution.md)。2026-10-25に、
[承認した契約](fread-multidim-proposal.ja.md)とSYSTEM_TASKS 6.3に従って実装しました。

`Lowerer::lowerFreadMemory`が他の引数より先に選択済みメモリの接頭添字を捕捉し、
線形の末端要素アドレスを数値の添字へ分解します。残る最右次元が最速で変化し、
残る次元が1つなら従来の実添字を使います。slot・frame・refは既存の`freadLeaves`と
カーネルの整数入力を共有し、VMにアドレス規則や新命令を加えません。

独立した直積・バイト文字列モデルを持つ[独自の生成器](../../tools/gen_multidim_fread_matrix.py)で
156件を検査します。5種類の範囲、1・9・32・65・129ビット、2値／4値、slot・automatic・ref、
既定値、startの明示・省略、count、境界、部分EOFの9シナリオを組み合わせます。
追加6件は、記述子・start・countの副作用より先の接頭添字の捕捉、残る1・2次元、待ちを検査します。
全件が通り、既存のIcarus 13.0比較の`multidimensional_fread`も通りました。
dev全体は3,659件中3,657件成功し、同じ既知2件をスキップします。

座標の進行、降順の走査、使い切ったcountを壊す3件を誤実装検査へ登録しました。
コンパイルした誤実装と4構成CIの結果は、配列メソッドの検証記録で追記します。
既存テスト本体・期待値・SIRダンプ29件・性能予算は変更していません。
動的メモリと多次元の構造体メモリはP1の残作業です。
