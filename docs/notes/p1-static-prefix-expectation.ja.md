# Issue #64 の期待値を分離して移行する

[English](p1-static-prefix-expectation.md)

この変更は実装を含まず、SystemVerilog の入力も変更しません。リポジトリの期待値変更方針に従い、
[Issue #64](https://github.com/kurochan001/kirimasim/issues/64) の実装とは別にレビューします。

`tests/dump_sir/procedures.sv` の `always_comb` は `mem[1][3:0]` を読みます。
既存の SIR 期待値は `mem[1]` の全 8 ビットを購読しています。IEEE 1800-2023 9.2.2.2.1 と
11.5.3 は最長の静的接頭部を指定するので、この要素のビット 3〜0 だけを購読する必要があります。
ビット 7〜4 だけの更新ではブロックを再開してはいけません。実装と独立した実行回帰テストで
この違いを確認します。

期待値の変更はこのトリガ範囲だけです。命令、書き込み範囲、プロセス順序、ソース位置、
形式の版は維持します。

移行だけでは旧実装は適合しません。実装変更はこの期待値移行に依存します。
両変更を別 PR とし、統合前に組み合わせた結果を検証します。
検査の緩和や、従来の広い感度を保つ実装は解決案に含めません。
