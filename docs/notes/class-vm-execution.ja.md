## 実行と所有

ロード時に class SIR を検証し、activation のレイアウトと実行時の値より先にヒープの記述を登録します。
構築用のラッパーには、先に公開して pin した receiver を渡します。基底の構築、宣言元の初期化子、
コンストラクタの本体、instance const の一度だけの初期化は、カーネルの段階の権限で実行します。
外へ渡した receiver は同じ識別子を保ち、基底の構築中の仮想呼び出しでは、派生の初期化子を
先取りせず安全な型の初期値を読みます。

プロパティの読み書きは、宣言元、静的な view、固定配列の順、広い値のマスク、二値・四値の初期値を保ちます。
生成、弱参照、動的な型を保つ浅いコピー、upcast、検査付き cast、識別子、seed はカーネルに任せます。
等価・真偽・不明な条件での選択も検証付きのカーネル API を使い、valsem の論理 ID の参照実装と照合します。

instance function と待機する task は、通常の引数束縛・戻り値・参照・copyback の経路を使います。
仮想呼び出しは数値の slot で解決し、直接呼び出しは指定した宣言を選びます。待機する呼び出しは解決後の
命令を所有し、task の入れ子やスタックの拡張・待機で copyback の位置を無効にしません。
構築の段階は invocation ごとに所有し、中止時に段階と pin を解放します。外へ渡した効果は取り消しません。

class のルートは整数の形から推測せず、型から列挙します。静的なスカラー・配列、通常の frame、
scoped/captured の格納域、実行中の native SSA、引数、戻り値、copyback、遅延した呼び出しの引数、
スケジューラの保留値を保持します。コンテナの class 要素は、ヒープとの境界で所有元タグを変換します。
ref は既存の格納域の生存規則を使います。pin は格納域を保ち、中止したプロセスの実行を延長しません。

## 検証と残り

追加22テストの行列は、構築の順と早期の仮想呼び出し、隠したフィールド、幅1・32・65・129・257と二値・四値、
配列、仮想・直接呼び出し、入れ子の待機、戻り値・output・ref、コンテナの push/pop、コピーの RNG と識別子、
cast、弱参照の失効、位置付きの null/const エラー、構築の途中の中止、遅延した呼び出し、schema の割り当て失敗を検証します。
生成元が終了した後に割り当てを繰り返し、変数・配列・コンテナ・オブジェクトの辺・遅延 NBA の保留値・
待機中の通常/scoped frame・親終了後の fork capture がそれぞれ保持することも確かめます。
識別子の演算は valsem と照合し、別の Context・古い世代・不正な null を拒否します。

依存する値の変更を待つ命令、monitor、procedural override、イベント回数付き NBA の記述、pattern の書式、
class 値を含む書式の引数、managed event のフィールド、標準外の `--init-values` の設定を
組み合わせた class 設計は、値を作る前に拒否します。
オブジェクトの依存グラフ、private フィールドの観測、event の所有、書式を接続するまでの境界です。
通常の数値の書式と時間による待機は実行できます。

property とコンテナ要素の ref・bit・NBA、slang の canonical な class の収集、ソースの lowering と
全配置の行列は残っています。既存のスイート本体・期待値・性能予算は変えていません。
以前の VM の拒否テストは、まだ未対応の managed event の格納へ入力を移し、元の全アサーションを維持しました。
今回の SIR 実行の接続では、機能プローブと P1 母集団は再測定していません。
実行の仕組みに18個の変異を追加し、既存の class の事前検査と3つの event 受け渡しの変異も、
元の不具合の性質を保って検証します。
