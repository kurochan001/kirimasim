# Icarusの機能範囲を目指すP1の拡張

[English](p1-icarus-progress.md)。状態：進行中、2026-10-23。

到達点は、Icarus Verilog 13.0以上の機能をP1で支えることです。
全面的な同等性は**未確認**です。従来の合格率や、下の小さなプローブだけでは
判定できません。P3・P4や対象外の機能を前倒しする
[範囲の修正](p1-icarus-scope-proposal.ja.md)は2026-10-23に承認され、
[P1_SCOPE](../spec/P1_SCOPE.ja.md)へ反映しました。

実装と検査を2回進め、次を追加しました。

- 共通カーネルによる無書式の `%u`・`%z` 出力。任意の幅、ゼロ埋め、X/Z、
  ホストの語のバイト順に対応します。生成するCLI行列は132プログラム・14,256変換で、
  ファイル・遅延・packed・文字列への出力を含みます。3本のユニットテストで、
  生の語、幅の上に不要なビットがある値、実行時の書式を確認します。文字列型では
  NULを除き、packedとファイルには残します。
- 参照引数のメモリへのreadmem/writemem。const refでのファイル出力、転送、待機、
  自動変数、選択した行に対応します。生成した63本は7種類の形と9種類の格納場所で、
  両基数、範囲、多次元、列挙型、隣の行の保持を確認します。この行列で見つかった
  部分的な `ref.make` は、`Lowerer::refOf` で残りの座標を補って修正しました。
  既存の期待値は変えていません。

変更前の `499198369a07` では、バイナリと参照メモリの新しいテストが、それぞれ
`%u` と ref の `$readmemh` の未対応エラーになります。今回の実装では通過します。
P1_FEATURESの日英の新しい実行例も実行して確認しました。

拡張した作業ツリーのローカルCIは、dev・release・ASan・UBSanの構成・ビルド・
テスト、releaseフラグ、禁止機能、SPDX、スイート、グローバル状態、README件数、
clang-format、clang-tidyが通過しました。devは1,572件中1,570件成功、
従来許可された2件のスキップです。既存テストの変更はアサーションと
CMake登録の追加だけです。新しいPythonのSPDXと、文書のリンクも確認しました。
公開前の検査では、未pushの各コミットについて既存の期待値の変更も検査します。

## 名前付きイベントの混合待ちと項ごとのiff

C ABI 0.3は `wait_mixed` を末尾へ追加し、既存のフィールド位置と関数の引数は変えません。
両APIは同じカーネルを呼びます。

guardを読む前のキャンセル、保留したトリガ、監視の初回評価前の登録を確認します。
C ABIテストは新しい入口と表の既存部分、SIRテストは名前付き項への辺の拒否を確認します。

## 承認済みの動的コンテナの共通ヒープ

2026-10-23に、利用者が本仕様の選択を含む動的配列・キューの修正案を承認しました。
実装前に、日英のSIR_SPEC 4.2.1とRUNTIME_ABI 6へ実行上の契約を反映しました。

`Context::heap()`が、世代を検査するコンテナと要素セルのトークンを持ちます。
`Heap::construct`・`copy`・`fromValues`と入れ子への書き込みは独立した値を作り、
キューの挿入・削除・移動は残るセルの識別子を保ちます。旧参照は切り離したセルを
読み書きできます。コピー・挿入には代入先のキューの上限を適用し、実行する層に
警告の種類を返します。平坦な要素配置は整数・実数・文字列・不透明なハンドルの語と
入れ子の型付きの辺を表し、slang・SIRへの依存はありません。

標準のメモリ資源を切り替えて確保します。確保失敗時は新しいコンテナ・セルをすべて
巻き戻し、変数・旧参照・出力用バッファを変更しません。公開操作はエラーを返し、確保の
例外を外へ漏らしません。コピー・回収は反復で行い、深い入れ子でもネイティブの呼び出しを
再帰させません。正確な回収は明示したコンテナ・セルのルートをたどり、到達する切り離した
セルも保ちます。解放した表は世代を変えて再利用し、印付けの失敗時は何も解放しません。
呼び出す層には、許された境界で全ルートを渡す義務があります。

14本の新しいカーネルテストで、整数の幅・2値/4値・上限の56通りを各450操作、
合計25,200操作確認しました。操作・回収ごとに、listを使う独立した
`valsem::ContainerValue`のモデルと比較します。2,500段の入れ子、実数・shortreal・
文字列・集約値の配置、同サイズへの再確保、自己コピー、上限での切り捨て、
構築・コピー・変更・印付けの各確保地点での失敗、4,096回の表の再利用、Context間の
分離も確認します。誤ったセル、入れ子の共有、巻き戻し時の漏れ、印付けの辺の欠落、
世代の無視、挿入位置の誤りの6つの変異を、補助ツールの検査を除く実テストですべて
検出しました。復元した実装も通過しています。

今回は共通カーネルの土台です。frontと実行する層はまだこのヒープの操作に接続しておらず、
SystemVerilogの動的配列・キューの対応と、境界での全ルートの自動公開は未完了です。
44本の比較プローブとIcarusで通る23本の差分は変わりません。本修正案とP1全体の目標の
完了を示すものではありません。
