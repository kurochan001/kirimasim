## 数え直し方

記録したいコミットのきれいなチェックアウトで：

```sh
python3 tools/project_size.py        # 上の表（HEAD について）
python3 tools/mutants.py --check     # 誤りの数
```

Issue の件数は GitHub から取ります（`gh issue list --state open` と `--state closed`）。Issue が動くたびに変わります。
