# Security policy

[日本語](SECURITY.ja.md) · This English text is the main version; the Japanese version follows it, and where they differ, this text holds.

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's private
vulnerability reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Do not open a public issue for a security
problem.

We will acknowledge the report, investigate, and coordinate a fix and
disclosure with you.

## Supported versions

kirimasim has not made a release yet. Until it does, only the latest commit
on `main` is supported.
